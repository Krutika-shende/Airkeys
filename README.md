AirKeys – Virtual Mouse & Virtual Keyboard Using Hand gestures

AirKeys is a computer vision-based application that enables users to control mouse movements and keyboard operations using hand gestures captured through a webcam. It provides a touchless and interactive way to interact with a computer without requiring a physical mouse or keyboard.

Features
- Hand tracking using webcam.
- Virtual mouse movement using hand gestures.
- Gesture-based clicking and scrolling.
- Virtual keyboard functionality.
- Touchless human-computer interaction.

Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- PyAutoGUI
- Pynput
